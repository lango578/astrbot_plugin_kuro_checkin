# 📣 自动签到结果推送教程

本教程介绍 **AstrBot 库街区每日签到插件** 的「自动签到完成后，把签到结果推送到你的聊天会话」功能。

---

## 一、功能说明

插件每天按配置时间（默认 `07:30`）自动执行签到后，会生成一份签到结果（鸣潮/战双游戏签到 + 社区签到 + 库洛币余额），并**主动推送**到你绑定的聊天会话，例如：

```
【库街区每日签到】
✅ 鸣潮 签到成功，奖励: 星声
ℹ️ 战双 今天已签到
✅ 社区签到成功，连签 12 天
💰 当前库洛币: 320
```

这样你**不用主动问**，每天到点就能在 QQ / 微信 / Telegram 里看到签到情况。

---

## 二、如何绑定「推送会话」

插件会把结果推送到 **`bind_umo`** 指向的会话。以下三种方式都可以设置推送目标（任选其一）：

### 方式 1：绑定 token 时自动绑定 ✅ 推荐

发送：

```
/库街区绑定 eyJhbGci...（你的 token）
```

或一键登录：

```
/库街区登录 138xxxx8888
```

插件会自动把**当前对话**记录为推送目标，无需额外操作。

### 方式 2：手动签到自动更新

任何时候发送：

```
/库街区签到
```

插件都会把**当前对话**更新为推送目标。适合你在新设备 / 新群聊里重新指定推送位置。

### 方式 3：WebUI 手动填写（一般不推荐）

在 AstrBot WebUI 的插件配置中有一个 `bind_umo` 字段（会话标识字符串，格式：`平台:消息类型:会话ID`，例如 `aiocqhttp:group_message:123456789`）。

> 一般**不需要手动改**，用方式 1 / 2 就会自动写入。

---

## 三、开关配置

在 AstrBot WebUI「插件配置」中：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `push_result` | `true` | 自动签到完成后是否推送结果。设为 `false` 则只写日志不推送 |
| `auto_sign_enable` | `true` | 是否启用每天自动签到 |
| `auto_sign_time` | `07:30` | 自动签到时间（24 小时制，**服务器时区**） |

推送目标（`bind_umo`）也会显示在配置中，方便确认绑到了哪里。

## 四、工作流程（技术原理）

```
时间到点 (auto_sign_time)
        │
        ▼
┌─ 定时循环 _auto_sign_loop()（插件 initialize() 时启动的 asyncio 任务）
        │
        ▼
┌─ do_sign_all()  依次执行：游戏签到 → 社区签到 → 论坛任务(可选) → 库洛币查询
        │
        ▼
┌─ _run_auto_sign()  检查 push_result == true
        │
        ▼
读取 config["bind_umo"]（绑定会话的唯一标识，格式：平台:消息类型:会话ID）
        │
        ▼
context.send_message(umo, MessageChain(...))  ← 主动发送到绑定会话
```

关键点：
- 会话标识 `bind_umo` 由 `event.unified_msg_origin` 自动生成，例如 `aiocqhttp:friend_message:123456789`
- 主动发送使用 AstrBot 的 `context.send_message()` API
- 定时任务在插件 `initialize()` 生命周期中启动，插件卸载（`terminate()`）时自动取消

## 五、常见问题（FAQ）

### Q1：自动签到成功了，但没收到推送？
按顺序排查：
1. 检查插件配置 `push_result` 是否为 `true`（默认开启）
2. 确认已绑定会话：发送一次 `/库街区签到`，插件会自动绑定当前会话
3. 查看 AstrBot 日志，是否出现 **"未绑定推送会话，跳过推送"** 或 **"推送签到结果失败"** 的提示

### Q2：换了一个群 / 换了设备，推送去哪了？
推送目标是你**最后一次**绑定 token 或手动签到时所在的会话。
在新会话里发送一次 `/库街区签到`，推送目标就会更新到新会话。

### Q3：推送失败，日志报 `qq_official 不支持此方法`？
**QQ 官方 API（`qq_official`）平台不允许主动推送**（官方接口限制）。
解决办法：
- 改用 `aiocqhttp` / `aiohttp` 等平台（推荐，`support_platforms` 已声明支持）
- 或在该平台用 `/库街区签到` 手动签到查看结果

### Q4：推送的内容可以自定义吗？
当前版本推送完整的签到结果文本（游戏签到、社区签到、库洛币）。如需要精简 / 定制格式，可修改插件 `main.py` 中 `do_sign_all()` 的返回内容。

### Q5：自动签到时间按什么时区？
按 **AstrBot 服务器的本地时区**（`datetime.now()`）。如果你的服务器是 UTC，需要把 `auto_sign_time` 相应换算。

## 六、配置速查

```yaml
# _conf_schema.json 中与推送相关的配置项
"push_result":     true      # 自动签到后推送结果到绑定会话
"auto_sign_enable": true     # 每天自动签到
"auto_sign_time":  "07:30"   # 自动签到时间（服务器时区）
```
